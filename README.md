# Radix Ateliê, site

Site de uma página da Radix Ateliê (impressão 3D personalizada, Florianópolis).

- `index.html`: página principal (HTML e CSS num arquivo só).
- `cores.html`: cartela de cores PETG.
- `img/`: imagens do site.

Para ativar os botões de WhatsApp, preencha `WHATSAPP` no fim do `index.html` (55 + DDD + número, só dígitos).
